Dates as YYYY-MM-DD or YYYY-MM-DDTHH:MM (this computer's time), or relative like -7d, -12h@h, now.

How it works

  1. Network analysis: give the base search for your web or WAF logs. Voyager splits the time range into windows, exports the request groups from Splunk, merges them and runs Payload Analyzer: injection attempts, campaigns, report.
  2. Entity mapper: search any value (an attacker address, a callback host, an account) across all indexes, then see which sources it appears in and how its relations evolve over time.
  3. Findings from the network analysis can be sent to the entity mapper with one click. Both run in the background; closing the browser or restarting Voyager doesn't stop them.
