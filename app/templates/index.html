Getting Started

Installation Steps

  1. Install the Userscript:

    You need the Tampermonkey BETA browser extension (identifiable by its red icon) to run this script. Install Tampermonkey BETA, then install the SplunkVoyager Cookie Extractor script below.

    Set your Splunk URL in Settings first; the script is generated for it.

    Install the Voyager session bridge

  2. Visit Your Splunk Instance:

    Navigate to your Splunk instance with the userscript installed. The script will automatically extract cookies and send them to SplunkVoyager.

  3. Start an investigation:

    Once your session is active, open Investigations to run the network analysis and the entity mapper.
